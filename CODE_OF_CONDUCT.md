# Code of conduct

ShockTrace adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In summary:

- Be respectful and inclusive. Harassment, discrimination, personal attacks and sustained
  disruption are not acceptable, in any project space or in public spaces when representing the
  project.
- Critique ideas, methods and code, not people. Disagreement about methodology is welcome and
  should be argued with evidence.
- Remember that the data describe vulnerable populations. Do not use project spaces to
  speculate about or single out individuals or communities.

## Reporting

Report unacceptable behaviour privately to the project maintainers (through the repository
host's private reporting or direct message to a maintainer). Reports are handled confidentially.
Maintainers may remove content, warn, or temporarily or permanently ban participants, following
the enforcement guidelines of the Contributor Covenant.
